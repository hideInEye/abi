# 本体网络开发计划

## 1. 范围与约束

- 属性建模保留现有真实功能，不回退为占位页；默认页签调整为"维度建模"，页签顺序保持"维度建模 / 指标建模 / 标签语义"。
- 新增实体定义、关系配置、图谱探索三个目录页面：`entity`、`relation`、`kggraph`。
- 页面目录路由由现有自动路由机制生成，不手动修改 `router/elegant` 生成文件。
- 样式复用属性建模和现有列表风格；需求文档中的独立样式细节不单独实现。
- 需求文档第 9 节对象字段建议不采用；请求、响应和前端类型严格以接口文档为准。
- 需求文档中的前端校验规则需要实现。
- 不运行构建和 ESLint。

## 2. 公共实现

### 2.1 目录与代码组织

```text
ontology-kg/
  entity/
    components/
    hooks/
    types/
    utils/
    index.tsx
  relation/
    components/
    hooks/
    types/
    utils/
    index.tsx
  kggraph/
    components/
    hooks/
    types/
    utils/
    index.tsx
```

- 组件仅负责渲染和事件转发。
- 接口适配、分页、校验器和数据映射放在 hook、utils 和 service。
- 新增统一接口文件：`apps/abi/src/service/api/ontology-network.ts`。
- 本体网络接口基路径：`/abi-ontology/v1/ontology`。
- 统一读取当前空间 `spaceId`，避免组件内散落读取 `localStorage`。
- 保存成功后关闭当前 Drawer 并刷新列表；删除前统一使用二次确认。

### 2.2 标签类型查询

```text
POST /abi-copilot/v1/label/get
```

请求参数：

```ts
{ spaceId, type: 'RECOMMENDED' }
```

响应 `data` 映射为：

```ts
{ label: bizName, value: id, bizName }
```

用于实体新增、实体编辑和实体列表标签类型筛选。

## 3. 实体定义

### 3.1 页面与接口

- 页面目录：`ontology-kg/entity`。
- 对接接口：
  - `entity/add`
  - `entity/list`
  - `entity/get`
  - `entity/update`
  - `entity/delete`
  - `entity/attribute/save`

### 3.2 列表

- 筛选条件：实体名称、实体编码、标签类型。
- 标签类型筛选使用标签 `id` 传 `labelId`。
- 表格字段：实体名称、实体编码、标签类型、颜色圆点、属性数量、创建人、创建时间、操作。
- 不展示备注列。
- 使用独立分页，列表数据取 `data.records`，分页数据取 `total/current/size`。

### 3.3 新增实体

Drawer 字段：实体名称、实体编码、标签类型、实体颜色、备注。

- 标签类型使用单选可输入 Tags 下拉。
- 加载 `RECOMMENDED` 标签作为下拉候选。
- 用户输入后回车生成候选值，最多保留一个标签。
- 新增请求传当前唯一标签文本至 `labelBizName`；标签不存在时交由后端自动创建。
- 保存成功后重新拉取标签选项与实体列表。

### 3.4 编辑实体

- 实体名称、实体编码锁定且不提交变更。
- 允许修改标签类型、颜色、备注。
- 标签类型选择已有标签，更新接口传 `labelId`。

### 3.5 前端校验

- 实体名称：必填、2-50 字符。
- 实体编码：必填、2-50 字符，符合 `^[a-zA-Z][a-zA-Z0-9_]{1,49}$`。
- 标签类型：必填且仅一项。
- 备注：最多 500 字。
- 实体名称唯一：调用 `entity/list`，传实体名称和 `pageSize: 1000`，前端做精确比对并排除当前编辑 ID。
- 实体编码唯一：调用 `entity/list`，传实体编码和 `pageSize: 1000`，前端做精确比对并排除当前编辑 ID。
- 错误提示使用需求文档定义，例如："实体名称已存在，请重新输入"、"实体编码已存在，请重新输入"。

## 4. 属性配置

### 4.1 入口与摘要

- 入口位于实体列表操作列，点击后打开右侧 Drawer。
- 先调用 `entity/get` 获取实体和完整属性列表。
- 顶部展示实体名称、实体编码、标签类型。

### 4.2 已绑定属性

- 页签顺序：全部、维度属性、指标属性、标签属性。
- 数量按当前草稿实时计算，新增和删除后立即刷新。
- 列表字段：属性类型、属性名称、属性编码、来源模块、删除操作。
- 不展示备注列。

### 4.3 新增属性绑定

固定交互流程：属性类型 -> 对应分组 -> 对应数据。

- 标签属性：读取 `tag` 分组和标签语义数据。
- 维度属性：读取 `ontology-dimension` 分组和维度数据。
- 指标属性：读取 `ontology` 分组和指标数据。
- 不提供 `field` 属性类型。
- 绑定资产下拉同时提供"绑定整个分组"和当前分组下具体资产。

接口不支持持久化 `groupId`、`bindingScope`：

- 选择"绑定整个分组"时，前端将分组内全部资产展开为多条标准属性记录后提交。
- 属性记录按接口字段组装：`attributeType`、`attributeCode`、`attributeName`、`dataType`、`relateDictId`、`remark`。
- 重复判断以 `attributeType + attributeCode` 为准。
- 已展开绑定整个分组后，再选择其中资产视为重复。

### 4.4 前端校验与保存

- 属性类型、绑定分组、绑定资产必填。
- 备注最多 500 字。
- 已绑定同一资产时提示"当前资产已绑定，请勿重复添加"。
- 点击添加只更新 Drawer 草稿和分类数量，Drawer 保持打开。
- 点击保存时调用 `entity/attribute/save` 提交完整属性草稿，关闭 Drawer 并刷新实体列表属性数量。

## 5. 关系配置

### 5.1 页面与接口

- 页面目录：`ontology-kg/relation`。
- 对接接口：
  - `relation/list`
  - `relation/add`
  - `relation/update`
  - `relation/delete`
- 预加载实体列表建立 `entityId -> entityName` 映射，供筛选、表格和 Drawer 使用。

### 5.2 列表与 Drawer

- 筛选条件：开始节点、关系名称、结束节点。
- 表格字段：开始节点、关系名称、结束节点、是否可逆、创建人、创建时间、操作。
- 不展示备注列。
- 新增/编辑 Drawer：开始节点、关系名称、结束节点、是否可逆、备注说明。
- 前端不展示、不传递关系接口的 `labelId`，由后端处理。

### 5.3 前端校验

- 开始节点、结束节点必填且必须取自实体定义。
- 开始、结束节点不能相同。
- 关系名称必填、2-50 字符。
- 备注说明最多 500 字。
- 关系组合唯一：调用 `relation/list`，带开始节点、关系名称、结束节点和 `pageSize: 1000`，前端做精确比对并排除当前编辑 ID。
- 删除前显示确认框，成功后刷新列表。

## 6. 图谱探索

### 6.1 页面与接口

- 页面目录：`ontology-kg/kggraph`。
- 使用项目已有 `@antv/g6`。
- 对接接口：`POST /abi-ontology/v1/ontology/graph`。

### 6.2 顶部查询与左侧过滤

顶部查询条件：开始节点、结束节点、关系名称关键词、关系跳数。

- 默认值：全部 / 全部 / 空 / 2。
- 跳数支持 1-5。
- 关系名称支持模糊匹配。

左侧过滤：

- 实体、关系名称均多选，默认全选。
- 取消实体时隐藏该节点和关联边。
- 取消关系时隐藏对应关系边。
- 点击重置恢复全选，并提示"筛选已重置"。

### 6.3 G6 画布

- 节点只展示实体名称和实体颜色标识，不展示属性数量。
- 边从开始节点指向结束节点，展示关系名称；未选中边使用浅灰色。
- 支持拖动画布、拖动节点、放大、缩小、重置视图。
- 拖动位移不超过 3px 视为点击；超过 3px 不触发选中。
- 节点位置只保留在当前前端会话；重置恢复默认布局。
- 图谱响应中的重复边按边 ID 去重，避免 G6 ID 冲突。

### 6.4 右侧详情

- 详情面板默认收起。
- 首次点击节点或边时展开；用户手动收起后保持收起，直至主动展开。
- 节点详情展示实体基础信息和维度/指标/标签属性分面板；属性仅使用小标签展示名称。
- 边详情展示开始节点、关系名称、结束节点、是否可逆、备注、创建人、创建时间。
- 图谱探索只读，不提供新增、编辑、删除。
- 空状态：无匹配时展示"暂无匹配的实体或关系"；无边时展示"暂无可展示关系"。

## 7. 验收与检查

- 实体和关系的查询、重置、新增、编辑、删除可用，且字段校验和提示符合需求。
- 实体编辑时名称、编码不可修改。
- 属性配置支持分类、分组联动、具体资产、整个分组、重复校验和数量实时刷新。
- 图谱支持服务端组合查询、左侧本地过滤、节点/边详情、拖拽、缩放、重置和详情折叠。
- 所有列表不展示备注列，备注仅在 Drawer 和详情中出现。
- 完成后仅执行静态路径、接口参数和手工页面验证；不运行构建和 ESLint。
