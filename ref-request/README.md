# ref-request（改造需求输出）

本目录用于沉淀对 `xindun` 前端工程的系统性审查结论与“可落地的改造清单”（偏工程/架构层面，不推倒重来）。

## 文件说明

- `00-project-overview.md`：项目整体认知（定位/技术栈/复杂度/当前架构画像）
- `01-issues-prioritized.md`：问题清单（按严重程度 P0/P1/P2 分级，附证据与影响面）
- `02-quick-wins.md`：短期可落地优化（1~2 周内优先项、验收口径）
- `03-mid-term-architecture.md`：中期结构性调整（模块边界/目录治理/状态与数据流治理）
- `04-performance-bundle.md`：性能与构建优化（bundle 现状、分包/按需加载/依赖治理、度量方式）
- `05-observability-security.md`：可观测性与安全（错误上报、性能监控、权限与 token 风险治理）
- `06-roadmap.md`：演进路线（分阶段交付、风险控制、里程碑与验收）
- `07-architecture-review.md`：架构师独立审查报告（含现有文档未覆盖的 12 项新发现，附优先级矩阵与执行顺序）

## 约定（用于后续落地）

- **不推倒重来**：优先通过“收口边界 + 渐进迁移”实现演进。
- **先止血再优化**：P0（安全/正确性）先解决，再做结构性重构。
- **每项改造都要可验收**：为每个需求定义可量化指标（如 bundle 体积、首屏时间、错误率、构建耗时等）。
