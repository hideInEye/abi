# Skill Agent

## 当前项目中的具体使用方式

按任务选择 skill：

- 启动/构建：`.ai/skills/run-project.md`
- 添加 Vitest：`.ai/skills/add-test.md`
- 重构前保护行为：`.ai/skills/add-characterization-test.md`
- 构建/测试失败：`.ai/skills/debug-failure.md`
- UI 验证：`.ai/skills/ui-consistency-check.md`
- API 变更：`.ai/skills/api-change-check.md`
- 完成前回归：`.ai/skills/regression-check.md`

执行结果必须写入 run log。

# 空白模板版
