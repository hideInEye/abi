# Knowledge Agent

## 当前项目中的具体使用方式

本项目需要沉淀的知识示例：

- 新增可用测试命令或修复根 lint/type-check 后，更新 `BUILD_AND_RUN.md`。
- 新增 Playwright 后，更新 `mcp/browser.md`、`skills/ui-consistency-check.md`、`TEST_CHECKLIST.md`。
- 新增共享包测试策略后，更新 `TESTING_STRATEGY.md`。
- 发现稳定架构决策后，新增 ADR。

不要沉淀：一次性端口占用、临时后端 500、未复现猜测。
