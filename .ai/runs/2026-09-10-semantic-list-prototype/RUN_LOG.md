## 实现说明

### 页面与视图

- 复用 `SearchFilterBar`、`ViewControls`、`abi-searchbar`、`abi-data-area`、`abi-toolbar`、`abi-std-table` 及系统卡片语言，不修改全局主题。
- 基础搜索按名称/编码模糊查询；“更多”包含名单类型、业务类别、状态、匹配目标和匹配方式。
- 操作栏提供新增、批量启用、批量禁用、批量删除、列表/卡片切换和列设置。列设置可控制七个业务列，操作列始终保留。
- 列表视图支持当前页全选与跨页保留选中；切换视图时清空隐藏勾选。卡片视图保留详情、编辑、状态切换和删除。
- 分页默认 20 条，支持页大小和快速跳转；筛选、重置、删除和页大小变化均收敛到有效页码。

### 业务功能

- 使用页面内 `useReducer` 和异步兼容控制器管理 7 条初始规则；不请求接口、不读写持久化存储，刷新恢复初始数据。
- 新建/编辑共用响应式 `CommonDrawer`，完成默认值、动态业务类别、字段级校验、高级 Key/Value 行及智能示例回填。新建编码按 `RULE_000008` 形式递增。
- 详情抽屉展示完整规则、命中示例和高级设置，三种匹配方式均可现场测试；正则新建/编辑时也可先测试再保存。
- 精确匹配为大小写敏感的整串相等；LIKE 支持 `%` 任意长度、`_` 单字符、转义其他正则字符并忽略大小写；正则使用 JavaScript 语义并兼容前置 `(?i)`。
- 高级设置忽略全空行，对有内容的单边或双边输入保留原值。单条与批量启停、删除都通过不可变状态转换更新数据。

### 弹层与边界

- 2026-09-11 响应式复审后，抽屉和删除确认框在桌面端均使用 `50%`；小于桌面断点时抽屉回退到 `96%`、确认框回退到 `90%`。宽度通过 Ant Design `Grid.useBreakpoint()` 计算，避免项目只注册 `sm` 的 ahooks 响应式配置使 `lg` 永远不可用。
- 表格的名单类型、匹配目标和操作列分别调整为 `120 / 120 / 260`，关键内容不换行；横向滚动宽度按当前可见列宽与 `48` 的选择列宽实时求和，隐藏列后同步减少。
- 页面局部在窄屏下将搜索栏、操作栏和分页换行，卡片切换为单列；弹层内部继续使用 UnoCSS 网格和弹性布局。
- 本阶段没有业务 API 或菜单接口变更。后端动态菜单仍需返回 `/component/data/semantic-list` 才会在真实环境显示入口。
