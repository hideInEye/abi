- 实现分层/分组命名、唯一性、安全字符、20/10/20/100 数量上限、逻辑连接、空值运算符、删除确认、首错定位及窄宽度自适应。
- 兼容旧版直接 `conditions` 的数据，保存统一输出嵌套 `groups`；关联字段递归去重收集。
- 字段树保持“维度/度量/日期 > 表 > 字段”，仅叶子字段可选，并保留搜索、加载、空态与失败态。

### 标签定义

- 在“标签定义”标题后增加带 Tooltip 和无障碍名称的“一键生成定义”图标按钮。
- 完整表达式编译为按分层顺序命中的 `CASE WHEN` SQL，覆盖 AND/OR、LIKE、NULL、数字值及字符串转义规则。
- 实现 `idle/generated/manual/stale` 抽屉会话状态、手工编辑识别、表达式变更提示和覆盖确认；生成结果继续写入可编辑的 `remark`。

### 指标建模

- 原子指标映射新增必填聚合方式 `projectionFunc`，默认 `sum` 并随映射记录提交。
- 普通派生指标移除可编辑聚合字段，从原子指标继承聚合方式、来源字段和语义数据，并展示只读来源卡片。
- 通过语义数据 ID 异步加载业务限定字段，处理详情回退、竞态、失败重试及切换语义数据时的条件清理确认。
- 调整步骤内容标题、基础信息字段位置和模块顺序；新增只含计算频率/执行时间的“预计算配置”。
- 支持每小时、每日、每周、每月四种执行控件、实时摘要及当前空间时区提示。
- 派生指标第二步新增统计口径：最近 N 小时/日/周/月、全天/指定时段和主体维度单选。
- `calcLogic` 新增 `precomputeConfig`、`statisticalCaliber` 和嵌套 `expressions[].groups[]`，读取兼容旧协议，并继续映射顶层 `updateFrequency`。

### 日期范围组合控件补充调整

- 保留数值字段的外层 `Form.Item`，通过受控 `value/onChange/id` 将表单状态传递给子组件中的 `InputNumber`；日期单位继续由子组件内的 `noStyle Form.Item` 独立绑定。
- “最近”改为数值输入框前缀，并使用 `Space.Compact` 组合数值输入和日期单位，布局与交互参考图一致。
- 定位到全局 `.ds-form-section` 的强制圆角会破坏 Compact 接缝；使用 CSS Module 仅覆盖本组件内部的左侧外圆角、中间直角和右侧外圆角，未修改全局表单或其他组件样式。
- 新增组件测试验证外层表单初始值可传入数值控件，且前缀、组合容器和日期单位正确渲染。
- 补齐 `InputNumber` 前缀组合内部 `group`、数值容器和输入元素的高度继承，使“最近”、数值输入框与日期单位下拉框上下边缘平齐；高度继续跟随系统控件尺寸，不增加局部固定高度。

### 原子指标来源字段展示补充调整

- 派生指标第二步选择原子指标后，来源卡片优先展示匹配语义字段或原子指标来源字段的 `bizName`。
- `bizName` 不包含指标创建使用的精确 `_#_` 映射分隔符时原样显示完整内容；包含时仅展示后半部分“字段名”；带空格的 `_ # _` 不做拆分，缺少 `bizName` 时保留现有技术字段名回退。
- 本次只调整只读展示文本，不改变来源字段 ID、表达式字段、聚合方式或提交协议。
- 修复历史派生指标回显：历史原子指标的 `techId` 只有长整型字段 ID、无法从已加载语义字段匹配名称时，单来源场景改为读取原子指标列表/详情项的 `rawBizName/bizName`，不再直接显示字段 ID。
