# 数据集编辑页左右两侧边距配色不一致修复

## 日期
2026-07-29

## 需求
数据集编辑页（/workbench/data-preparation/data-collection-operate/:id）左右两侧各出现一条与面板配色不一致的竖条边距，视觉上不协调，需要统一。

## 原因分析
- 页面外层 ACard 容器在 `index.module.css` 中只清除了 card body 的上下 padding，左右仍保留 antd 默认 24px 内边距，露出容器的淡紫灰渐变底色。
- 左侧配置面板背景为 `rgba(255,255,255,0.4)`、右侧维度/指标导航条为 `rgba(255,255,255,0.5)`，均偏白，与两侧边距条的灰紫色形成明显色差。

## 修改内容
1. `index.module.css`：`.container > div` 由 `padding-top/bottom: 0` 改为 `padding: 0 !important`，左右面板直接贴到卡片边缘，消除两侧杂色条。
2. `[id].tsx`：左侧面板容器 `pr-16px` 改为 `px-24px`（补回自身左右内边距，与原先卡片 24px 内边距的视觉宽度一致），背景由 `rgba(255,255,255,0.4)` 统一为与右侧导航条一致的 `rgba(255,255,255,0.5)`。

## 影响范围
仅数据集编辑页（data-collection-operate）布局与配色，不涉及逻辑。

## 追加：SQL 模式按钮还原与退出编辑（2026-07-29）
- SQL 模式不再展示顶部共用操作栏（退出编辑/保存），恢复底部操作栏布局：执行 | 保存 | 格式化。
- 底部新增「退出编辑」按钮，使用全局 `btn-accent-gradient` 类，与数据语义编辑页「下一步」按钮风格一致。
- `SqlModeEditor` 新增 `onSave`/`onExit` 回调 props，由 `[id].tsx` 传入保存与返回列表逻辑；图形化模式顶部操作栏不变。
- 底部操作栏按钮全部改用全局样式类（去除内联 style/size）：执行、退出编辑用 `btn-accent-gradient`，保存、格式化用 `btn-ghost-v5`。
