# 静态资源盘点清单说明

## 当前状态

- 本文和同目录 CSV 仅保留为盘点证据，不是前端迁移计划，也不授权修改资源位置。
- 用户负责图片、图标、字体及其他静态资源的手工处理。
- 2026-09-24 已撤销本轮预置的 `VITE_STATIC_ASSET_BASE_URL`、三应用 `src/static-assets` 映射和相关运行时解析逻辑。
- ABI 的 12 个 SVG 已恢复到原 `apps/abi/src/assets/svg-icon/` 目录；不存在 `svg-illustration` 运行时引用。
- 当前所有本地资源继续使用现有路径。CSV 中的建议 URL、状态或目标路径不驱动代码。

## 清单口径

- CSV 记录扫描时识别到的大型图片、SVG、字体和组件缩略图，以及大小、引用场景、CORS/Canvas 风险等信息。
- “未引用候选”只能作为后续复核线索，不能直接删除。
- 删除任一图标或资源前，必须同时通过源码引用扫描、生产构建和真实页面回归。
- 清单生成后若资源发生变化，应重新扫描，不能依赖旧大小或旧引用结论。

## 用户完成手工处理后的前端工作

1. 用户提供明确的新文件位置或绝对 URL，以及允许修改/删除的具体文件列表。
2. 前端按独立需求调整对应引用，不迁移清单外资源。
3. 对图片验证尺寸占位、加载优先级、错误态和桌面布局。
4. 对字体验证格式、Content-Type、CORS、`font-display`/FontFace fallback。
5. 对参与截图或导出的图片验证匿名跨域和 Canvas 不被污染。
6. 运行三个应用生产构建、Chunk 定向测试和关键页面回归。

## 本轮保留的独立优化

- ABI 登录背景和登录插画保留固定宽高；唯一 LCP 候选保留高优先级。
- Dashboard 字体不在 `/projects` 启动阶段全量注册，而是按项目数据加载，并使用 `display: swap`。
- ABI 本地图标按需读取并归一化根 SVG 尺寸，不恢复全量 Sprite 首屏注册。

## 禁止据此执行的操作

- 不因 CSV 中存在 `test_url`、`production_url` 或状态列而接入云基础 URL。
- 不把仍在使用的 SVG 从 `svg-icon` 移到其他目录。
- 不在缺少用户明确路径与真实云对象时删除本地回退文件。
- 不修改 Nginx、后端、正式环境或云存储配置。
